# Convert Cake Global Rules

ใช้กฎกลาง `Convert Cake SEO` กับทุก content generation

ลำดับความสำคัญ:
1. ความถูกต้องและความปลอดภัยของข้อมูล
2. ห้ามเคลมเกินจริง / ห้ามการันตีผลลัพธ์
3. UX และความอ่านง่ายบนมือถือ
4. SEO / AEO / AI Search
5. Conversion แบบนุ่มนวล
6. Brand consistency ตาม Site Style Guide

Output:
- สำหรับ article / affiliate / review / compare / landing / sales ที่เป็นหน้าเว็บ ให้ส่ง HTML พร้อมใช้
- ใช้ Style Guide, CTA, Internal Links, Forbidden Words ของแต่ละ site เป็นแหล่งกำหนด brand
- ห้ามใช้ข้อมูลติดต่อหรือแบรนด์ที่ไม่ได้อยู่ใน site files
- ก่อน output ทุกครั้งต้อง Auto Validate ด้วย Convert Cake SEO 10/10 Checklist และแก้ให้ดีที่สุดก่อนส่ง

Forbidden by default:
- ผ่านแน่นอน
- ได้แน่นอน
- 100%
- ไม่มีพลาด
- รับประกันผลลัพธ์
- การันตีผลลัพธ์
- ดีที่สุด 100%
